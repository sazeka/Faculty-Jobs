## Other Repository-Created Artifacts

Unless otherwise stated in a specific file, other repository-created artifacts (for example derived metadata organization and schema/documentation files) may be used for research, teaching, and non-commercial analysis with attribution.

## Attribution

When publishing results, cite the dataset DOI if you used a deposited release, or this repository otherwise, and include:

- repository URL
- snapshot date used
- access date

Use `CITATION.cff` for citation metadata.
