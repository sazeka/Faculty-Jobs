# Faculty Atlas Benchmarking Register

This register defines the benchmark suite for Faculty Atlas. It separates release gates from monitoring metrics and research audits so that improving coverage never comes at the expense of classification precision.

## Benchmarking principles

1. **Precision before coverage.** An unsupported appointment-track label is worse than an unclassified listing.
2. **Abstention is a valid outcome.** `unclassified` and `variable` must be evaluated separately from binary tenure-track accuracy.
3. **No circular validation.** A policy rule cannot validate itself. Precision labels must come from the posting, an independent official policy, an external dataset, or a separate human review.
4. **Stratify before aggregating.** Report results by evidence type, institution type, discipline, medical/non-medical status, source platform, and appointment class.
5. **Freeze inputs.** Every published benchmark records the job snapshot date, external-feed snapshot, code commit, sampling seed, and methodology version.
6. **Show denominators and uncertainty.** Percentages without counts are not sufficient. Precision and recall reports should include confidence intervals once labels are available.
7. **Prevent metric gaming.** A lower unclassified count only counts as an improvement when precision, false-positive rate, and variable-track handling remain stable.

## Status definitions

- **Ready:** implemented and runnable now.
- **Partial:** supporting data or checks exist, but the benchmark needs consolidation or human labels.
- **Proposed:** not yet implemented.
- **Manual:** requires independent review rather than automated scoring alone.

## Recommended benchmark rounds

### Fast release gate

Run for every appointment-policy or classifier change:

```bash
npm run benchmark:appointment-tracks
npm run verify:policy
node --test scripts/__tests__/weekly-tenure-stats.test.js scripts/__tests__/appointment-track-audit.test.js
npm run verify:data-sync
```

Block release if a policy source is missing, an active policy match cannot be resolved, a regression test fails, dataset copies differ, or totals change without an explained cohort.

### Monthly accuracy round

1. Generate the 200-record appointment-track audit sample.
2. Independently review all policy-dependent and explicit-language controls.
3. Review variable-track and unclassified cohorts separately.
4. Run the frozen EJM comparison.
5. Report precision by class and evidence tier, not only overall agreement.
6. Publish errors, abstentions, denominators, and confidence intervals.

### Quarterly research round

1. Double-code at least 50 records and calculate inter-rater reliability.
2. Audit discipline and position-type precision.
3. Measure institution, geographic, and source-platform coverage.
4. Measure listing and closure latency.
5. Review temporal label stability and canonical-ID churn.
6. Revisit thresholds using accumulated labeled evidence; never loosen a safety threshold merely to improve coverage.

## Standard benchmark result fields

Every benchmark report should include:

- benchmark ID and methodology version;
- generated timestamp and dataset snapshot timestamp;
- Git commit and sampling seed;
- population definition, exclusions, and sample size;
- counts before percentages;
- result by relevant strata;
- false positives, false negatives, ambiguous cases, and abstentions;
- confidence interval when labels are sampled;
- comparison with the previous benchmark;
- pass, warning, or fail status with the exact threshold;
- links to frozen inputs, review rows, and adjudication notes.

## Current baseline

The 2026-09-23 snapshot records 22,466 listings: 21,168 binary classified, 205 explicitly variable, and 1,093 unclassified. A completed 200-record single-reviewer evidence audit found one false tenure-track label in the frozen pre-fix sample (University of Florida Clinical Hospitalist Assistant Professor, whose posting explicitly says `Non-Tenure-Track Faculty`). The classifier now gives decisive current-posting language priority over stored and institution-policy values; the same frozen sample has 200 of 200 post-fix agreements. This is useful evidence, but it is not a substitute for AT-16's independent two-reviewer round.

The 2026-09-23 external EJM comparison matches 15 of 30 eligible advertisements (50.0% overall; 55.6% at institutions already represented in Faculty Atlas) and finds 12 agreements in 12 evaluable tenure comparisons. Because the evaluable external sample is below 30, the 100% agreement remains descriptive rather than a release-grade precision estimate. The gap audit identified three safe source-side gains for the next scrape—Marist's official PageUp faculty feed and two Cornell AcademicJobsOnline titles—and deliberately leaves the remaining external-only or access-blocked ads as coverage findings rather than importing the benchmark into the catalog.
