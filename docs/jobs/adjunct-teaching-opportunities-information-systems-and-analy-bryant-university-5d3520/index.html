Course Descriptions: AA630 Data Management and VisualizationThis course equips students with practical skills and knowledge in managing and manipulating data using Python and SQL, two of the most essential tools in modern analytics. Students will gain an in-depth understanding of relational databases, including schema design, normalization, and query optimization. They will

learn to write efficient SQL queries for extracting, transforming, and analyzing data from databases, applying advanced techniques such as joins, subqueries, and aggregations. The Python component of the course focuses on importing, cleaning, transforming, and summarizing data for analysis. Students will work with real-world datasets, applying Python libraries like pandas and numpy to handle data preprocessing and

manipulation tasks. Emphasis will be placed on building seamless workflows that integrate Python and SQL for end-to-end data management solutions. Through practical assignments and a project, students will apply their skills to solve data management challenges, demonstrating their ability to handle complex datasets and provide actionable insights.
