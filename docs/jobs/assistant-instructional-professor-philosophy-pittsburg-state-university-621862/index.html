Assistant Instructional Professor - Philosophy Pittsburg, KS, United States Be the First to Apply Job Description Pittsburg State University invites applications for the position of Assistant Instructional Professor of Philosophy. The successful candidate will teach introductory courses in philosophy, ethics, and logic, as well as upper-division courses on topics within philosophy. The ability to teach an

introductory course on world religions would be viewed positively. The normal teaching load is four classes (12 hours) per semester. The appointment will begin in January 2027.
