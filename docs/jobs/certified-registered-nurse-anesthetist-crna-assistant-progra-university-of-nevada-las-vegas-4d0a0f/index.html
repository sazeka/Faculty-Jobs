Job Description The University of Nevada, Las Vegas

invites applications for Certified Registered Nurse Anesthetist (CRNA) Assistant Program Director/Assistant/Associate/Professor-in Residence, School of Nursing [R0152623] ROLE of the POSITION The Certified Registered Nurse Anesthetist (CRNA) Assistant Program Director/Assistant/Associate/Professor-in-Residence or will work closely with the CRNA Program Director to provide vital leadership for the CRNA Program track
